# 视频节拍阶梯

把画面证据变成可以复刻、看得懂变化的过程，再按请求发散和制作完整提示词。开场吸引力、可见进度、过程因果、空间一致性与结尾兑现共同决定质量，不由拍数多寡决定。

## 路由与交付

| 用户请求 | 执行与终点 |
|---|---|
| 反推视频节拍／阶梯 | 看源片，交付带证据的观察阶梯、叙事结构、疑点与空间冲突；不自动发散或生成提示词。 |
| 根据视频给创意 | 先完成观察，再发散；交付点子、推荐项和每项保留／改变之处。 |
| 没有视频，给点子 | 从约束发散；全部标为原创设计，不虚构源片或观察时间。 |
| 制作全套提示词 | 从已有观察或所选创意进入空间设计和生成阶梯，完成全部 IMAGE／VIDEO 正文和文件。 |
| 直接发散并制作全套 | 若未选方案，采用本轮推荐项并说明；继续完成，不反复请求确认。 |
| 修正人物变化／比例／空间穿帮 | 对照人物参考与空间账本，分别定位外观、尺度和空间问题；保留原记录，修订生成设计及受影响段落。 |
| 视频排查／优化 | 审阅全片，交付有时间证据的问题、优先级及原拍到修改的对照；不把编辑判断冒充留存数据，不自动生成全套正文或重做视频。若请求优化本技能，提炼可复用规则并修改技能，片例与运行记录放任务目录。 |

默认：中文说明、英文生成正文、八个创意候选、Omni、每段十秒素材、普通施工段按信息需要选择工作镜与接触镜。用户明确的数量、语言、模型、时长、镜头或风格优先。十秒是素材规划，实际入口的模型名称、时长选项和参考能力要核对。

只生成提示词不调用图片／视频生成，不因首帧未渲染而扣住其余正文。用户要求渲染时使用当时可用的工具与授权；本技能不绑定服务地址、账号或自动入库。

## 三层分离

1. **观察阶梯**：只写实际审阅到的画面／音轨，记录来源时间、不确定性和疑似矛盾。文件标题、观众评论、已有提示词是线索，不能充当画面证据。
2. **创意与修正设计**：记录保留的吸引力、变更的载体／工序／空间及设计依据。未知尺寸可保持未知，或明确另设设计值；不能冒充源片实测。
3. **生成阶梯**：为可生成的段落拆合动作、补中间状态并映射原拍。新增特写、扩挖、供料、电源交代等标为生成设计，不回写为原片事实。

原片观察完整保存。生成默认修正已确认的比例和空间矛盾，采取最小改动并列出修正；源片不清楚则标未知，不凭猜测大改。若用户明确要逐镜原样复制，保留其选择并单列未解决的冲突，不能宣称已校正。

**优先级：反推节拍为主，优化在其上进行。** 有参考片的任务默认保留有效的动作顺序、阶段成果、节奏层次和揭晓目标；先忠实还原，再增强比例、空间与因果。不要以“优化”为由删掉重要原拍、套成固定模板或另写一条无关故事。优化版给出“原拍→保留／拆分／补充／调整→原因”的对照；只有用户要求大幅改编，或修复明确冲突确实需要时，才重构相关局部。只请求反推时可以附优化建议，仍以完整原片阶梯为主要交付。

## 执行顺序

### 看证据

使用 Python、FFmpeg、FFprobe 与 Pillow。把下面 `<skill>` 换成本技能的实际目录，路径加引号：

```bash
python3 "<skill>/scripts/extract_video_evidence.py" --video "/path/source.mp4" --output-dir "/path/job/evidence"
```

先看全片分页图，再在动作分界、材料层、人物与开口关系处检查原尺寸帧。工具提取不等于已审阅。全片基线保持每秒两帧，开场第一秒逐帧，必要区间加密；不把单幅总览当完整分析。采样帧只证明“此刻已发生”，时间写“首见于”，用于定剪点的时刻先逐帧复核（见反推方法）。

每拍至少有具体动作／揭晓、前后可见状态、时间和证据。允许单动作、短闪帧、没有新施工痕迹的运镜。连续重复劳动不机械碎拆；同机位不同表面或材料层的升级不被合并吞掉。先建立完整时间覆盖，再解释疑似变化候选。

诊断时把“已见事实、编辑判断、待复核、用户偏好”分开。先核对用户指出的问题是否在本片实际发生，再补查其他问题。短闪图／标题、重复进退场、特写前后偷进度、未兑现的开场承诺和重复尾镜都需回查；无观看数据不宣称已证明流失原因。

### 先锁人物与空间，再写正文

这一步的完整设计用于制作提示词；纯反推只记录可见关系、未知值和优化建议，允许空间方案尚未规划，不强迫为源片补造尺寸。

根据 `spatial-consistency.md` 建立一套共享空间账本：人体参照、外壳和内部平面／剖面、开口、家具、承托面、相机族及空间连接。每个尺寸区分已知、估计、设计和未知。

有人物的生成方案同时按 `character-consistency.md` 建立人物合同：外观、体型、身高依据、服装基态、实际参考或待制作参考及允许变化。各段继承同一人物；多人分别记录尺度。新制作的结构化提示词包填写 `spatial_contract.actors` 和逐段 `actor_ids`，无人段填 `[]`；旧包不为升级检查而重写。

实际渲染前核对人物参考能否进入所用入口、自动改写后哪些约束仍生效，以及工作构图能否看清人物头脸和尺度参照。已有视觉基准但没有实际传入，不算已绑定。只收首尾图且不能另绑人物时，按人物手册制作独立动作锚点；保持无人空间状态与动作锚点的用途分开。文字交付仍可用 planned 参考，不冒称画面已经稳定。

室外还需锁定真实作业边界与主机位可见范围，写清前、中、后的显著变化。范围不足以支撑选定主题时，扩展有因果联系的作业区；用户锁定小范围则在原边界内增强可读性。构图稀释变化就调整工作机位。放大人物、推近相机或改变曝光不算扩大施工范围。

检查人能否站立和通过、家具能否放下和搬入、室内是否容于外壳或具有单独来源、窗外是否存在可解释的暴露立面。圆形外壳不能在剪切后无解释扩大成长方形大厅。人像占画面比例不跨景深和姿态硬锁。

提示词写完后，核对逐段人物识别特征和服装状态，再按空间手册检查账本数值与正文用词、人物与场景参照、表面状态的来源与去向、无人状态安排或已说明的动作锚点适配、单镜头动作量。人物外观、人体尺度、空间连续性分别记录结论。纯文本包可以完整交付，但 `render_review.status` 保持 `not_run`；检查失败的设计先修正，不能全表填“通过”。

### 创意与提示词

按请求读取相应参考。发散前先区分用户指定的用途、排除项等硬约束与“最好／优先”等偏好，并检查每项候选是否满足；要求结合最新网络热点时，先核验带日期、地域和出处的近期信息，再让热点具体影响画面设计，详见创意方法。先定义首屏具体冲突、主要改造范围和对应的最终回报，再规划中间变化；不靠堆叠“极致破旧”等形容词代替设计，不强迫新建题材脏乱破损。每个生成段有一个清楚的可见结果；`source_beat_ids` 保留来源，原创或新增过程注明 origin。普通施工按有效信息选择主工作镜→接触特写→回到同机位的路线；特写无新信息时可连续宽镜，真实局部接触可以推进，但不得暗中完成未展示的大面积工程。开场、桥接与揭晓按观看目标组织。

线性链 N 段视频使用 N+1 张静态边界。空间状态图默认无人，人物与尺度参照可放在辅助设计参考中；实际入口需要带人物动作锚点时，按 Omni 手册记录它与无人状态的对应及实际绑定。窗口、洞盖、隐蔽材料层和裁切外家具继续存在，不因为当前看不见而重建。

最终揭晓默认无人，以已完成空间、功能或核心装置兑现开场；不为告别、摆拍、展示满意表情或尺度复核刻意补人。用户指定人物使用演示或逐镜复刻时遵从。施工收尾的人物动作和最终成品镜头分开，不强迫每段演一遍完整进场退场。

### 检查并完整交付

反推、创意或提示词交付在 job 目录保存 `beat_package.json` 并按合同校验。仅视频诊断／技能优化可以使用证据索引、诊断报告和审阅记录，不强造生成链。校验器只核对可核对的结构和证据索引，不负责看片，也不证明图像正确或开场吸引人。

完整提示词请求应交付：全包文本、图片与视频分包、逐段复制文件、源片与生成时间索引、空间账本、审核记录；有反推和创意时附相应结果。只反推或只创意不强造其余产物。

长任务按批写入同一任务目录，保存已完成的段号与审阅记录；继续时从真实产物恢复。全部段落写齐后再标记完成，不用“同上”或模板占位。

运行结果默认放当前工作目录 `outputs/<主题>_<时间>/`，也遵从用户指定位置。不要修改源视频、清空别的任务、把运行台账写进技能文件夹或覆盖旧交付。

## 生成画面的人物与比例复核（仅实际生成后）

在人物实际出现的开工、中段、收尾施工动作里，分别检查身份外观与尺度，并查看宽镜、接触特写、返回镜头、门洞穿越及第一次室内画面。外观对照人物参考与服装状态；尺度对照相机、姿态、深度、承托面及稳定实体。遮挡后重现、转身和换空间处重点复核。不能只看无人首尾帧，也不为复核向无人终景补人。另按视觉叙事参考检查真实首屏、同机位可见改造量、接触位置和进度、结尾兑现；文本写过约束不算画面验收通过。

人物一直裁头或脸始终模糊时，身份未验证；脚下承托面和可比实体看不见时，尺度未验证。先修构图和实际参考绑定，再重渲受影响段，不用“未发现换人／伸缩”替代缺失证据。关键状态变化前后加密核查，区分可省略的重复劳动与必须看见的穿戴、交接和过门动作。

失败时回到共享空间账本定位根因，修复有问题的参考、图或片段，并复核相邻边界；不要让下一段沿用错误锚点。重试遵从现有授权与工具约束；同一缺陷最多两次额外尝试，仍失败就调整设计或分镜并记录未通过，不靠无限重复或剪掉所有人物证明合格。

## 完成标准

- 观察覆盖可见变化并允许不确定性；没有追求固定拍数。
- 新增过程与源片事实分开；人物外观、空间和人体比例有可检查的参照，允许的服装／状态变化有来源。
- 创意／优化／提示词的首屏冲突能被具体描述，主要改造量可见、动作位置与成果相符，终景兑现承诺且人物安排符合请求。
- 完整正文、编号和相邻锚点闭合，来源映射完整。
- 原片复核、结构检查、设计检查、生成验收各自如实标记。
- 结果路径可访问，用户可以直接复制和导入；不宣称单靠提示词永久消除所有生成漂移。
