# 视觉吸引力、变化幅度与结尾兑现

用于创意设计、视频优化和完整提示词制作；已有成片诊断时对照实际证据判断。
纯反推照实记录原片，以下要求只作为独立的编辑建议，不改写观察事实、不伪造工序，也不为满足规则删掉原片有效节拍。
用户明确指定的题材、范围、镜头和人物安排优先。行为标准用于改进画面，不代表观看数据或播放效果保证。

## 1. 首画面先成立，再安排第一段

开场应让观众直接看见“值得改变的状态”或“想继续看的问题”。先写清这些内容，再写风格形容词：

- **视觉焦点**：第一眼看什么，位于哪里，轮廓、材质、明暗或空间关系怎样让它从背景中分离。
- **具体冲突**：什么可见状态不寻常、阻碍用途、构成鲜明反差，或引出尚未解决的问题。
- **变化承诺**：接下来的工作将改变什么；第一段的动作与这个问题有直接关系。
- **兑现路径**：哪些中间结果证明问题正在被处理，最后怎样看见承诺已经兑现。

“极度破旧”“非常脏乱”“震撼”不是画面证据。把需要强化的状态写成可生成、可观察的实体关系，例如堆积物遮住主要通道、破损面暴露连续材料层、狭小入口与待建空间形成可解释的悬念。
只选择服务主题的主冲突，避免同时堆叠污垢、坍塌、火灾、洪水等互不相干的刺激。
修复题材可以强化可信的破损、污垢或失序；新建、制作、自然场景可使用结构奇特、功能冲突、尺度反差、材料转化或空间发现，不强制制造污染与破损。

以破、脏、乱为吸引力时，程度必须作用于主要观看对象：例如连续大面遮蔽、关键通路堵塞、主体构件明显缺失，让终态能产生显著对照。只有零星缺瓦、小片苔痕或几件散料，整体已接近漂亮成品，又没有其他强冲突时，判为需要增强；不能因出现了一点破损就认定 hook 已成立。显著改变仍须能沿后续工序实现，不设计后面无法兑现的开场。

检查首画面和开场动作：

- 缩小到正常观看尺寸、静音观看时，主体和问题仍能读懂；不能依赖说明文字才成立。
- 镜头没有先把关键冲突挡住，或用无目标的环境巡游耗掉开场。
- 人物首次有效动作直接接触目标，或清楚揭示待解决问题；摆姿势、走近与准备不自动成为有效推进。
- 若先闪现完成态，闪现应建立具体期待，后续仍有发现空间；不强制每条片都采用预告成品。
- 首画面的问题在中段和结尾有去向，不靠换场景遗忘它。

原片开场偏弱时，先尝试加强既有冲突的可见程度、调整构图或前移有效接触；必要时再设计更强初态。
新增破损、清理量、开口或障碍都属于生成设计，并须同步工序、状态图与终态，不能只改第一张图片。

## 2. 室外范围既要真实足够，也要在画面里看得见

先区分两个问题：实际设计只改了很小一块，还是设计范围合理却被机位拍得过小。分别修正，不能用推近镜头冒充扩大施工。

室外方案在空间账本中补充：

| 项目 | 记录内容 |
|---|---|
| 作业边界 | 哪些地面、立面、结构、通道或附属区域属于本次施工；哪些背景保持不变。 |
| 功能关系 | 各区域如何共同服务所选用途，为什么需要施工到这里。 |
| 可见范围 | 主工作镜能看见哪些区域，人物、工具和环境是否遮挡主要变化。 |
| 阶段状态 | 初态、中间态、终态各有什么可辨的轮廓、材质、层次、边界或使用条件变化。 |
| 形成来源 | 扩大工程时增加的清理、开挖、供料、安装和废料去向如何进入生成阶梯。 |

并排比较同机位前、中、后视图：普通观看尺寸下，应能说出“哪里改变了、改变到什么程度”，而不是只能看见工人在动。
施工关键区域应成为画面的主要观看对象；保留必要环境地标，避免广阔未改背景持续淹没成果。
通过表面更新、结构成形、空间疏通或功能建立获得变化，不仅依赖换光线、调色、增加烟尘或切特写。
不设通用施工面积、画面占比或颜色变化阈值；根据题材、景深、透视和工序作判断。

按最小更改原则处理：

1. 已有范围足够时，先调整机位、遮挡和成果展示方式。
2. 现有动作覆盖不清时，明确其沿哪个区域推进，并补可见中间状态。
3. 范围本身偏小时，扩大与用途相连的作业面或相邻功能区，说明理由并同步材料、节拍和空间设计。
4. 不为变化强行改掉整片环境，也不凭空扩建无关房间；用户锁定小范围时，在该范围内优化可读性。

## 3. 每段有回报，镜头服务动作

生成阶梯的每段写明：观看目标、主要动作、可见终态差异、变化区域，以及哪个镜头证明差异。
施工段通常交付进度；桥接段交代空间关系；揭晓段提供已有成果的新视角或使用价值。不能要求所有段都发生施工。

- 重复劳动可以时间压缩，但变化应随有效操作累积；不以静止等待后的大面积瞬变代替过程。
- 相邻段若动作、机位与可见结果都难以区分，合并重复劳动、调整覆盖范围或突出不同阶段成果；保留确实不同的材料层和重要工序。
- 普通施工的主工作镜→接触特写→返回是默认组织方式，不是所有段必须套用的节奏模板。
- 接触特写应证明工具、工艺、接缝或材质变化；可呈现同一接触动作本身造成的局部变化，不能借裁切推进宽镜外工程。
- 对照特写前／中／后，核对同一对象、工作位置与姿态、周边材料层、完成量。背景面层也继承当前状态；收口、软装、床品和灯具阶段同样检查，不因主体已完成就放松。
- 返回镜继承已发生的局部变化，并以连续的后续操作到达既定终态；不重置进度，也不突然完工别处。
- 不用增加景别替代实际变化，不把每次取料、入场、离场都拆成独立回报。
- 开场、空间转换与最终揭晓按各自观看目标设计镜头和时长，不强制重复普通施工三镜头。

阶段回报既可以是大范围可见更新，也可以是决定功能成立的关键细节；关键细节应交代它与整体的关系。
最后一段施工结束时，主要成果已经成立。揭晓期间只能展示、运镜或按既定设计启用已有功能，不能偷增家具、灯具、窗洞或空间。

## 4. 结尾默认让成果成为主角

生成设计中的最终 reveal 默认无人：展示完成后的主体、功能、材质和环境关系，并回应首画面的核心问题。
不安排为了收尾而站立合影、回头微笑、挥手、走进画面或展示工人成就的表演。
用户明确要求人物，或人物使用本身是已选主题的核心回报时可以例外；记录人物的观看作用，避免遮挡主要成果。

收尾施工中已经存在的人物可以自然完成动作、收手或离开；离场不必成为独立尾镜，也不为每段无人锚点反复表演进出场。
人物比例复核覆盖人物实际出现的施工动作与空间转换，不为校尺或验收向无人终景补人；保留成片之外的尺度参考。
原片已有尾镜人物时，观察记录照实保留；优化版再说明保留、减少或移除及其理由。

终景检查：主要问题是否解决、核心改造范围是否可见、前后关系是否能对照、最后的停留是否提供新信息或欣赏价值。
检查最后一次切换、最后两秒及末帧是否出现短闪回或无意重置。两次相近揭晓若没有新信息可合并；有不同空间、功能或视角回报则保留。循环尾镜应是明确设计，不能用意外回跳充当循环。
不要只拍与前期施工无关的漂亮细节，也不要用暗光、裁切或人物遮挡掩盖尚未完成的工作。

## 5. 诊断和验收如实分层

每个问题记录：阶段或时间／帧号、可见现象、影响解释、确定程度、最小修改、受影响的状态图与段落。
明确区分：画面证据、用户偏好、编辑判断、待核查的生成缺陷。看不清时保留不确定性，不将推测写成事实。

- **未检查**：没有审阅对应文本或画面。
- **设计已检查／需修改**：只针对创意、阶梯和提示词是否落实可见条件；不代表实际画面通过。
- **画面符合／不符合／待复核**：实际审阅后结合时间或帧证据判断，说明检查范围。
- **未渲染**：文字包可以完整交付；`render_review.status` 保持 `not_run`。

这些是报告语义；写入已有结构化字段时遵从数据合同的枚举，不擅自扩展校验器状态值。
没有观看和留存数据时，只能说“首屏冲突不易读”“阶段变化弱”或“存在节奏风险”，不能断言观众必然流失、留存已提升或播放量会增长。
已有数据时也区分观察相关性与因果判断。结构校验通过、提示词包含强化词、单张图片好看，都不能代替整段视觉复核。
