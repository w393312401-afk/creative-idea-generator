# 空间、人体比例与因果连续性

在创意定稿、生成阶梯和提示词制作前读取本文件。目标是把尺度矛盾拦在设计、参考图和生成验收三个位置；文字约束不能保证生成模型永不漂移。本文件用于视觉叙事与生成连续性，不用于实际施工设计或承重验算。

结构化记录沿用 [交付包合同](package-contract.md) 的 `spatial_contract` 与 `render_review`，本文件补充其判断方法。无可靠实测时 `reference_height_m` 可为 `null`，相对 H 关系写入语义账本；文本交付的 `render_review.status` 保持 `not_run`。

## 1. 先判定证据，不把评论当测量

观众截图提供的是问题线索。回看原片后分别记录：可见矛盾、需要核对、未展示、观众偏好。截图说“没有工具”“没有电线”不证明原片全程没有，也不证明灯具没有供电。

- **原片观察**照实保留，包括不合理的空间变化；看不见的工序保持未知。
- **生成纠错**默认修正已确认的比例／空间冲突，另建空间设计和新增节拍，明确哪些来自观察、哪些是推断、哪些是为复刻新增的设计。不能把新增扩挖、线路或外立面写回原片事实；用户明确选择超现实空间时，将该选择记为创作意图。
- 优先处理会使观众无法理解空间来源的矛盾，再处理尺度漂移、动作接触和设施来源。缺少厨房或卫生间只有在用户要求完整住宅等用途时才成为设计缺口；卧室主题不自动扩建。

## 2. 提示词前建立空间合同

用一张紧凑表配平面／剖面说明锁定下列内容。可先用文字或简单线图，不要求自动渲染，更不要求用户逐图确认。

| 项目 | 必须确定的内容 |
|---|---|
| 人物 | 按 [人物合同](character-consistency.md) 固定 actor ID、外观参考、骨骼比例和体型；设计身高记为 H。多人分别用 H_A／H_B 并记录其关系，不把每个人强制设成等高。原片无可靠尺度时只用相对单位；原创可选定尺寸，但须标为设计值。 |
| 空间 | 各房间与外壳 ID、形状、宽深高、地面标高、厚度占用、相邻与包含关系；未知观察值和选定设计值分开。 |
| 开口 | 门洞、入口、地洞、窗的位置、朝向、净空及连向哪里；人物通过姿势和大件进场路径。 |
| 参照实体 | 同一扇门、床、台面、梯子等的稳定尺寸／相对 H 比例；为各相机视角选可见地标。 |
| 机位族 | 外景、施工宽景、接触特写、下层、窗景等 camera ID；相机位置／高度、朝向、画幅和视角设定；实拍无法标定时写定性约束，不伪造焦距。 |
| 允许变化 | 哪些节拍确实改变墙面、开口、房间范围或地面标高；变化前后状态及其原因。其余实体尺寸保持固定。 |
| 室外作业范围（如适用） | 真实施工边界、保留区、屋面／立面／地面／核心装置中本题实际涉及的区域，以及各主机位能看见的范围；前中后的显著改变与物料、废料、进场路径。面积和范围使用设计或估计标记，不伪造实测。 |

平面用于核对“房间放在哪里、门通哪里、家具能否放下”；剖面用于核对“上层／下层在哪里、人物能否站立、洞口和坡外窗相接吗”。同一份合同贯穿所有创意、状态图、镜头和提示词；不能每段独立重新设计。

只给室内尺寸且外壳不改时，保留已知内尺寸与“不扩壳”的约束，未知外尺寸、厚度可保持未知。只有内外切换、包含关系、净空或施工层确实依赖这些值时，才选定最少的设计假设并记录影响；不为填表凭空指定统一墙厚，也不把待定关系宣称已通过数值包含检查。

室外同时检查“工程真的只做一点”与“工程不小但镜头看不清”，处理方法不同，见 [视觉叙事与回报](visual-storytelling.md)。放大施工范围须有相关用途和形成过程，不重画建筑尺寸、不强制改造整片环境；工作镜头可以靠近，但要保留能验证真实边界的全貌关系。

### 人体尺寸与屏幕大小分开

锁定的是世界中的人物和物件尺寸，不是人物占画面的固定百分比。针孔投影中归一化位置为 `x = X/Z, y = Y/Z`，所以深度、姿势、视角和相机移动都可能改变画面占比；参见 [OpenCV 相机投影说明](https://docs.opencv.org/5.0/main_modules/calib.html)。

- 比较同一人物与处于近似相同深度的门、床、台面，结合站立／弯腰／蹲姿核对；不同深度不能直接用像素高比判错。
- 工人从远处走近、蹲下或进入广角边缘时，画面占比可变；骨骼比例、实体尺寸、与地面的接触关系不能无因改变。
- 同一机位族回到宽景时，检查墙地交线、开口和参照实体。相机后退或更换视角可解释构图变化，不能解释实际房间突然容纳了原本放不下的家具。
- 不设未经校准的“误差小于 5%”等统一通过阈值。若图像无法区分透视变化与实体变形，标为待复核，补同深度参照或更清楚的对照视图。
- 成片状态图可以无人。另保留同空间、同机位的人体校尺参考或带尺寸的设计图，不强迫把标尺、尺寸文字或人物画进每张成片图。

先看宽镜有没有足够证据：人物头顶与脚下承托面、参照实体及比较所需的深度关系。只见半身或只见无人场景时，不能验收整体人景比例。改变工作构图后重新核对相机族和地标，保持世界几何不变；人物变小或房间变大不能当作裁切问题的修复。

### 把尺度关系落到镜头里

在任务空间账本中为有人物的机位族记录：人物 ID 与 H 来源、脚下承托面／标高、可比较的门／床／台面等参照实体、相关尺寸或 H 比例，以及相机位置和人物深度。正文写清本镜相关关系，不能只写“比例正确”。工具和手的特写继承该工作位置、人体和构件尺度，不重新设计一双手或一套工具大小。

状态交接先核对未改变的参照，再核对本段工程改变的实体。铺地板后以新完成面计算净高和门槛；做饰面后扣除净宽。只有工程明确改变时更新这些数值，镜头推近、裁切和人物变大都不算工程范围扩大。

参考不够时，先写定性或 H 关系，并在审核中标出待复核项；不填假米数、不加未经校准的像素容差。已设计的数字与相对词冲突时先修文字；实际画面疑似缩放时补同深度参照或相同机位对照，再判断是相机变化、姿态变化还是实体变形。

相机前推、视角拓宽和多人分别走近同时发生时，人物与物件的投影可能向不同方向变化；不能只凭像素高度差判缩水，也不能把无法排除的漂移记为精确尺度通过。若关键比例仍难判断，保留原过程的未知项，用同一已核验空间中的固定工作机位补可比参照，或分开人物走位与运镜；不要再独立抽取一个新房间消除疑点。补拍只验证其实际覆盖的关系，不替原转换过程改判。

多个已知尺寸、不同身高或高低地面共同参与时，先做可读的空间草图或同坐标块模型。列出地面标高、头顶／家具顶的世界高度、门楣净空及搬运路线；用它发现必须弯腰、串行或改变朝向的阶段。给生成入口的图仍须检查是否保留这些关系，文字算术正确不证明图中门宽、人物高度和脚下台阶正确。

## 3. 空间必须有来源和去向

**外壳与内室：** 圆形外壳可以容纳方形内间，但平面和剖面必须证明内间在外壳内部，并为壳体和饰面保留占用。若方间更大，需选择可解释的设计：明确扩挖、独立下层、相邻空间或改小内间。只有镜头切换不能成为空间扩大的原因。

**小洞与大厅：** 先分清画面中的小洞是入口还是整个开挖范围。入口小于房间并非天然矛盾；但需要能追踪的通道／地洞，以及房间存在或扩挖的依据。生成纠错若增设扩挖，增加对应过程和土方离开画面的交代；不必逐铲展示，但不能凭空获得大客厅。

**地下窗景：** 剖面中窗外必须真实连接外部，例如坡地露出的侧壁、已建立的采光井或相邻外露立面。完全埋入山体的墙面不能直接接远处山谷。先确定空间位置，再决定揭晓镜头；换一张漂亮窗景不算修复。

**通行与接触：** 检查工人穿门、下洞、梯子落点、脚与支撑面；大件家具需有可通过的开口、组装过程或已存在的解释。人体／家具不得缩小穿洞后恢复原尺寸。地板叠层会占用净高，墙面叠层会占用净宽，不会扩大室内。

放手、退场或切空景之后，继续检查已落位物件与同一地面的承托和相对位置；手离开不等于落位完成。固定机位的起止锚点若要求本应静止的刚性物件无因改变尺寸、脚点或深度，先修受影响锚点，不能让成片靠脱手后的滑移、缩短或悬浮接上尾图。核对可见的承托点，真正被遮住的保持未知，不要求家具变透明。

**跨空间桥：** 外→内、上→下、门→房间等转换各记录入口和出口，并安排至少两个可追踪地标，分布在转换前、过程或转换后，例如洞沿＋梯子、门框＋相邻墙角。不要求每帧都看见全部地标，但须有可连起来的路径、方向和机位关系；特写不能承担整段空间跳跃的遮掩。

多层空间写明所在层、楼梯的上行／下行方向和目标层。换位或叠化可以省略行走，不能将上行与下行、屋顶层与下层的关系混作连续移动。地面增加构造层时，同步完成标高、门槛、首末级台阶与护栏的相对高度；纯观察无法量化时只记录疑点。

## 4. 把来源补进生成阶梯

每个新增成果写清“输入实体／工具 → 接触动作 → 状态变化 → 去向”。它帮助决定需要补哪一拍，不要求所有过程都出现多拍。

- **灯光：** 区分灯体安装、供电建立和点亮。电线不可见可以是已建立的暗线、明确的电池灯或其它选定设计；需要新增铺设时，应安排在覆盖饰面之前。只能将真实可见内容标为观察，其余是设计解释。
- **工具：** 能看见的操作应有与动作相符的工具、握持和接触点，材料变化紧随操作发生；没有展示工具的原片保持“未展示”，生成版可补必要接触特写。
- **工作位置：** 宽镜中的作业面、支撑高度和特写对象必须相连。递料不等于安装；人在窗边递瓦不能自动完成屋面。换到屋面、墙脚或另一面墙时，交代可读的工作位置转移；螺钉／胶缝等应落在明确连接对象上，不只展示工具在空表面运动。
- **材料和废料：** 入场、安装、遮挡、收走的状态相连；禁止同一块板材既装在墙上又完整留在地上，禁止“清理”特写暗中完成整个房间。
- **用途：** 先履行已选功能。评论提出的额外房间作为创意候选，不能自动挤进既定面积或改变主题。

## 5. 从设计参考传到每个提示词

先组成设计接触板：外壳和内室的平面／剖面、人物全身校尺、关键同深度物件、机位族宽景、入口到室内的连续关系。接触板是参考集合，不是让模型输出一张包含所有镜头的拼图。

可用现有照片、已核验状态图、简单线图或轻量空间块模型。文字制作任务只需把参考需求、设计值和锚点引用写完整；用户请求生成时才制作／提交相应参考，避免擅自调用付费渲染。

复杂多层空间或反复出现尺度漂移时，优先采用同一份有固定单位的简易三维空间模型：外壳、室内、开口、人物替身和家具占位共享坐标，再从既定机位输出构图参考。这样可以在设计层直接发现放不下、通不过和窗外被山体挡住的问题。该参考是新增设计依据，不是原片的精确三维重建；生成模型仍可能偏离，仍需看成片。简单场景不必为了套流程强制搭三维模型，也不能让这一步取代节拍反推。

- 对每张成片图保留 scene ID、actor ID（如有人）、camera ID、当前层级状态和相关固定参照；各段引用同一实体参考，不只重复“保持一致”。
- 每条英文提示词展开本段相关的正向关系：谁与谁同深度、脚落在哪一层地面、开口连向哪里、回到哪个机位；附必要的禁止项，如不扩大房间、不改变人物骨骼比例、不移动门窗。不要粘贴与当前画面无关的整份合同。
- 起止图均从已核验的空间状态继承。仅有首尾图不能证明中间运动正确，也不能保证尺寸不会漂移。
- 施工宽景 → 接触特写 → 原机位宽景：特写继承同一工人、工具、接触位置、材料层和已完成范围；允许镜内接触产生局部结果，回宽景先接上这个结果，再推进同类操作。不能在特写时突然多完成一整面墙，也不能回到已被覆盖的裸墙／旧饰面，除非明确是另一保留区域且能追踪定位。
- 若服务支持实体参考、首尾帧或其它约束，使用已核验引用并核对当次接口能力；不假定任意模型都支持同一套字段。新机位必须服从既有空间，不把独立随机生成的新房间作为相邻场景。

### 提示词写完后的文本一致性自检

账本和各条正文是分开写的，改一边忘了另一边，是最常见的漏洞；这类矛盾渲染前完全看得出来，到生成后才发现代价最高。所有正文写完后，逐项核对并把结果记入审核记录，不只写“已检查”：

1. **账本数值 ↔ 正文用词。** 正文用相对说法（“肩宽”“齐腰高”“一人高”）描述账本里有数值的实体时，按 H 换算后与账本比对，列“实体｜账本值｜正文用词→换算｜是否一致”。重点是大件进场的开口净宽高：账本里的 0.75 m 书柜不能穿过正文里“肩宽”（约 0.5 m）的拱窗。不一致就统一改成一个说法，两处不能并存。
2. **表面状态的来源与去向。** 开场出现的污渍、霉斑、水痕、锈蚀、裂缝、临时支撑，要么在某一拍被清理、覆盖或修复，要么到终景仍存在并写进终景正文。终景写“干净／崭新／完整”的表面，回查它在前面各图里的状态，不能凭空洗干净。
3. **默认空间状态图与无人终景不引入人物。** 这类图片正文不出现人物名词，也不为交代尺度写“a man standing for scale”；尺度用无人尺度物（标准门、椅子、台阶、灯具）或辅助设计参考。已说明、审阅并用于实际绑定的带人物动作锚点，按人物／PPE／尺度／空间映射审核，不适用本无人条款。校验器会对未说明的人物名词报 `image_prompt_people` 警告，但它查不出本节其余几项。
4. **单个镜头的动作量。** 一个约两秒的镜头只承担一个可读的变化；同一镜头里完成两个以上成果（切开三扇窗、装完一圈书柜）时，拆镜、拆段或明确降级为概括性画面，并在审核记录说明风险。

有人物的段落另对照人物合同，列“段号｜人物 ID／外观状态｜机位／承托面｜参照实体及尺度关系｜继承或变化依据｜结论”。文字没有脸部细节的特写不编造一张脸，但手、袖口、肤色和工具应属于该人物。共享账本变化后检查所有引用该实体的段落，不能只改首次出现处。

## 6. 分开报告文本检查与渲染验收

**尚未渲染：** 检查合同、空间包含、来源、开口通行、生成节拍和提示词引用。报告“设计／文本已检查，生成画面未验收”；不能把完整提示词等同于已根除画面错误。

**已有渲染或用户要求生成：** 按机位族和转换链核对设计参考、所有状态锚点、前后宽景、特写接触、跨门洞过程，以及每段中途出现的人物。快速抽检后对移动、遮挡、转身和疑似变形处加密，不能只验首尾。

身份外观按 [人物复核](character-consistency.md) 单列；尺度与空间按本文件单列。记录“人物／实体｜前后帧或时间｜姿态／深度／机位是否可比｜实际关系｜结论与处理”，未知或被遮挡的关系标待复核。外观相同不证明尺度通过，尺度稳定也不证明没有换脸。多人分别对照其参照与相互高度关系，不用统一 H 掩盖角色之间的变化。

每项记录为通过、失败、待复核或未渲染，并保留问题时间／帧号和具体关系。通过依据须能描述为“同一门框与工人在可比深度下关系稳定，移动可解释”，而非“看起来高级”或仅靠提示词包含某个词。

发现失败后只修受影响的状态图、相邻衔接段和共享机位族，复核传播范围；不要无故重做全片。针对同一缺陷的重复渲染最多追加两次，且每次都在已有生成授权和成本范围内；不自动付费重试。仍失败则改小布局、拆开动作／运镜或改用可约束的参考方式，保留失败标记，禁止包装成合格成片。

## 7. 对照例

| 问题线索 | 生成版修法 | 复核依据 |
|---|---|---|
| 圆壳切成宽大方室 | 内嵌可容纳的方间，或明确另建下层／扩挖来源 | 平面与剖面的包含关系；外内转换地标；同人物参照 |
| 洞很小，随后出现大客厅 | 区分入口与开挖区；补足连接、扩挖或预存空间的设计交代 | 人能按既定姿势通过；房间边界增长有来源；家具入场可解释 |
| 人一剪辑就变小 | 固定 actor 和世界尺度，以同深度门／床校尺，继承相机族 | 前后宽景与中段工人，排除蹲姿和深度变化后仍无实体变形 |
| 地下墙突然有山景窗 | 将窗布置在坡地外露侧壁，或改为已建立的采光结构 | 剖面、窗朝向与外景相符，窗位置在各镜头不跳动 |
| 有灯没线、有成果没工具 | 选择有依据的电源设计；补必要的安装、接触或覆盖节拍 | 来源在点亮／完成前已成立；同工具同接触点，未编造原片事实 |
| 没有厨房或卫生间 | 先核对主题；确有需求时重新规划空间和节拍 | 满足用户用途且放得下；不凭评论自动增加房间 |

不进入成片的辅助图优先选择：带 H 标尺的平面／剖面、人物与门床同深度站立图、入口到房间的路径图、同机位前中后对照板。这些图服务检查和生成参考，成片中无需出现标线、文字或多格拼图。
