# Hollow Oak Tree — Threshold Mode Restoration

## Demonstrates

Threshold routing with exterior → bridge → interior transition inside a hollow tree trunk. This example demonstrates:
1. **Closed-Trunk Start Logic**: Eliminates the logical error where the door is already carved in early images. Images 1-3 maintain a closed trunk with solid weathered bark, and the portal is carved in Video 3 (exposed in Image 4).
2. **Zero Man-Made Traces in IMAGE 1**: Image 1 shows a 100% wild, pristine natural starting state.
3. **Plausible Material Logistics**: Materials (steel bands, door frame, PVC conduits) are carried in by the worker in Videos 2, 4, and 5 exactly when needed, rather than mysteriously lying on the forest floor from the start.
4. **Complete 17-Beat Video Chain**: Completes the truncated video prompts from the user's input to form a coherent, contiguous time-lapse, and inserts the light-fixture installation beat the raw input skipped (a bulb never glows without an on-camera fixture install on the wired ends).
5. **No Grid Annotations (NLVTR compliant)**: All grid references (e.g. Grid C1, Grid B2) are removed and replaced with natural language coordinates (e.g. bottom-left, center, foreground) to prevent models from rendering grid overlay text on images or videos.
6. **Provenance-Safe Peek Anchors**: The two landmarks pre-visualized through the carved portal are natural heartwood features (a thick vertical heartwood ridge and a natural burl shelf) that already exist inside the sealed trunk — never future construction products like the spiral staircase (carved only in Video 10) or the writing desk (carried in during furnishing). Their frame-height scales rise monotonically across the bridge frames (one-fifth → two-fifths → three-fifths).
