# 反推性能优化验证

本次保留全量采样、逐帧事实字段、峰值高清复核及节拍校验。未更换模型，未减少送审帧数。

## 已落地

- review_frames 改为一次 FFmpeg 连续解码，按时间戳选帧。保持原文件名，支持同一帧对应多个时间点和可变帧率；尾部没有可选帧时沿用旧单帧回退。平衡表达式避免长视频超出 FFmpeg 解析深度；微秒容差避免小数边界误选后一帧。
- 峰值复核每批成功后原子写入独立缓存。缓存由模型、提示词版本和内容、图片 SHA256、裁切策略共同标识；失败不缓存，重启可继续。
- 多帧回复被截断时直接拆批，不再原样重复至三次。格式错误保留既有恢复路径。

## 验证

素材：Construction and Restauration (@constructionandrestaura)_3.mp4，323.033秒，842个采样点。

- 新批量取帧单项：23.739秒。
- 完整分析/抽帧/拼图流程：89.080秒；同视频历史 extract 阶段记录260.9秒，约2.9倍。历史和本次系统负载不同，此数字不是严格同环境A/B基准。
- 842张新抽取画面与项目历史原尺寸PNG逐像素比对：全部一致。
- 310个测试及6个子测试通过。包含恒定/可变帧率、重复取帧、小数时间边界、片尾、缓存复用及图片/模型/版本失效、失败不缓存、截断拆批。
- git diff --check 通过。

基准产物：C:/Users/video/.agent-runtime/bench_reverse_20260905/benchmark.json 和 full_benchmark.json。
