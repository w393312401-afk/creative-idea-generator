# 「API 配置中心」极简布局方案

目标：把一条 10 项的长滚动表单 + 一个嵌套弹窗，换成"左分区导航 + 右单分区表单"的
两栏窗口，并把**号池管理并进同一个窗口**。不改任何生成/号池逻辑，**所有控件 id 原样
保留**，因此 `js/config.js` / `js/account_pool.js` / `app.js` 里按 id 取元素的读写
全部照旧（只有显隐那几行从写死 `display:block` 改成还原成空串，见下）。

对照现状：[index.html:1329](../index.html#L1329)、
[css/app/settings-center.css](../css/app/settings-center.css)、
[js/config.js](../js/config.js)、[js/account_pool.js](../js/account_pool.js)。

---

## 一、旧版为什么不好用

| 问题 | 具体表现 |
|---|---|
| **一条长表单，找一项要滚** | `modal-body` 里 10 个等权 `.form-group` 竖排，每项下面还挂一段两三行的说明；480px 宽 × 90vh 高，改「生图宽高比」要滚过 FX 的四项模型设置。 |
| **顺序不按"改什么"排** | 帧序列后端 → 激发搜索词 → 参考网址 → FX 生图/视频/时长 → 换号频率 → 浏览器编号 → 号池入口 → 宽高比 → 清晰度。后端相关的被激发参考劈成两段。 |
| **号池是 modal 叠 modal** | 「🎬 生成号池管理」再开一个 `#account-pool-manage-modal`，盖在配置窗口上；而"选号策略"（换号频率 / 指定浏览器编号）留在下面那层，改一个要来回开关两个窗口。 |
| **改完不按保存就白改** | 除激发页脚的 LLM 模型、帧序列卡片的生图模型（这两处早就是"改动即存"）外，其余项必须点底部「保存配置」；直接叉掉窗口静默丢弃。「恢复默认」更隐蔽——它只写表单不落盘。 |
| **说明文字压过控件** | 每个 `<small>` 都是 `style="opacity:.65"` 的行内样式，字号与正文同级，视觉上和控件抢位。 |

## 二、目标布局

### 桌面（>768px）

```
┌──────────────────────────────────────────────────────────────────┐
│ ⚙️ API 配置中心                              ✓ 已保存        ✕   │ ← 头 56px
├──────────────┬───────────────────────────────────────────────────┤
│ 🔌 生成后端  │ 生成后端                                          │
│ 🖼️ 生图参数  │ 帧序列走哪条链路，以及 Google FX 侧用哪个模型      │
│ 🎬 生成号池  │                                                   │
│ 🌐 激发参考  │ 帧序列生成方式   [ 🔌 API 接口（LLM 网关）    ▾ ] │
│ 🧩 系统      │ FX 生图模型      [ 🍌 Nano Banana 2          ▾ ] │ ← 仅 FX 后端
│              │ FX 视频模型      [ Veo 3.1 - Lite …          ▾ ] │
│   168px      │ ─────────────────────────────────────────────── │
│              │ 模型选择已移至使用现场：LLM 在激发按钮上方…       │
├──────────────┴───────────────────────────────────────────────────┤
│ 测试连接                              恢复默认        完成       │ ← 脚 56px
└──────────────────────────────────────────────────────────────────┘
                        900 × 660（max-height 88vh）
```

窗口**定高**：切分区时窗口不跳；长分区（号池）自己在右栏内部滚。

### 移动端（≤768px）

左栏折成顶部横向滚动的芯片行，字段从「label 左 / 控件右」退回竖排，
窗口高度交回 `panels-tabs.css` 的移动端补丁（`height:auto` + `max-height:90vh`）。

## 三、五个分区怎么切

按「一次要改的东西」聚在一起，而不是按参数类型：

| 分区 | 内容 | 为什么在一起 |
|---|---|---|
| **🔌 生成后端** | 帧序列生成方式、FX 生图/视频模型、Omni Flash 时长 | 都被 `imageBackend` 这一个开关串起来；后三项在 api 后端下整体隐藏。 |
| **🖼️ 生图参数** | 宽高比、清晰度 | 封面与帧序列共用，跟后端无关，改的频率也不同。 |
| **🎬 生成号池** | 折叠的「选号策略」（换号频率 / 指定浏览器编号）+ 号池列表 + 一键导入 + 添加行 | **本次最大的改动**：策略和池子本来就是一件事（"用谁、多久换一次"），拆成两层窗口纯属结构债。 |
| **🌐 激发参考** | 联网搜索词、参考网址 | 只影响随机激发的取材，跟生成链路无关。 |
| **🧩 系统** | 托管模式说明、清理系统缓存 | 一年点不了两次的东西，不该占首屏。 |

号池分区的纵向分配：分区撑满右栏，**只有账号列表滚动**，
「📥 一键添加全部」和「➕ 添加」两行永远钉在视野里（账号可以有几十个，
旧版那样跟着列表往下推，加号得先滚到底）。选号策略默认折起——它是
"设一次就不动"的参数，摊开会把列表挤到折叠线以下。

## 四、改动即存

配置中心的每个控件 `change` 即落盘，跟激发页脚的 LLM 模型选择器、帧序列卡片的
生图模型选择器统一约定。反馈只在头部闪一个「✓ 已保存」（1.6s）——每改一项弹一次
toast 太吵。底部按钮相应变成 `测试连接 / 恢复默认 / 完成`。

实现（[js/config.js](../js/config.js)）：

- `applySettingsFormToConfig()` —— 从表单收值进 `config`，不落盘。`saveConfig()`
  与 `autoSaveConfig()` 共用，避免两条写入路径读的字段集合漂移。
- `autoSaveConfig()` —— 收值 + 落盘 + `flashSettingsSaved()`。**不调 `checkApiStatus()`**：
  本表单没有一项会改变 LLM 网关路由（那由 `config.model` 决定，入口在激发页脚）。
- 绑定用事件委托挂在 `#settings-pane` 上，新增字段自动纳入；号池分区
  （`.account-pool-manage-body` 内）排除在外——那些控件各自直接打服务端。
- `resetConfig()` 末尾补 `applySettingsFormToConfig()` + 落盘：它只改 DOM，
  不收回来的话持久化的还是用户的旧值（旧版靠事后点「保存配置」兜底）。

## 五、迁移注意

1. **`#account-pool-manage-modal` 已删除**，内部 markup 原样移进
   `<section data-section="pool">`。`openAccountPoolManageModal()` 保留为
   "打开配置中心并切到号池分区"的入口；`closeAccountPoolManageModal()` 已移除。
2. **显隐一律用空串还原**：`updateFxImageModelVisibility()` /
   `updateFxVideoDurationVisibility()` 原先写 `display:block`，而字段行现在是
   CSS grid（`.settings-field`），内联 `block` 会把 label/控件/说明拍回竖排。
3. **`fx-pool-strategy-group`**（包住换号频率 + 浏览器编号的 `<details>`）跟着
   两个子项一起显隐，否则 api 后端下号池顶上会剩一条点开是空的「选号策略」。
4. **停留分区记忆**在 `localStorage['spark_settings_section']`；进 `pool` 分区时
   顺带 `loadAccountPool()` + `loadAccountPoolAdspowerProfiles()`。
5. `css/app/settings-center.css` 必须排在 `base.css` 之后加载：要覆盖那里的
   `.modal-content` 480px 上限与 `.form-group` 竖排 flex。
